# AI Agent Manager

AI Agent Manager is a multi-tenant governance runtime for B2B SaaS teams that want to deploy, control, audit, and monetize AI agents safely.

## What this repo contains

- `docs/marketing/` — positioning, homepage, FAQ, objections, and email sequence.
- `docs/sales/` — pitch, call script, pricing, and sales enablement.
- `docs/product/` — security, governance, revenue model, and case study template.
- `docs/architecture/` — system architecture and operating model.
- `docs/launch/` — pilot-first launch plan.
- `prompts/` — reusable prompts for Claude Code and the AI Lead Gen Agent.
- `skills/` — Claude Code skill for AI lead generation.
- `scripts/` — scaffold, validate, and index helpers.

## How to use this repo

1. Start with `docs/marketing/positioning.md` and `docs/marketing/homepage.md`.
2. Use `docs/sales/pricing.md` to frame the commercial offer.
3. Review `docs/product/security-governance.md` before any enterprise conversation.
4. Use `docs/launch/launch-plan.md` to execute a pilot-first rollout.
5. Use `prompts/claude-code-repo-builder.prompt.md` to generate or extend the repo.
6. Use `skills/ai-lead-generation-operator/SKILL.md` to generate outreach, content, ads, partners, and referrals.

## Operating principle

Lead with governance, not features. Lead with tenant safety, not agent novelty.

## Repository standards

- Security-sensitive files are protected via `.github/CODEOWNERS`.
- Vulnerabilities are reported via `SECURITY.md`.
- Contributions follow `CONTRIBUTING.md`.
- AI agents must follow `AGENTS.md`.
