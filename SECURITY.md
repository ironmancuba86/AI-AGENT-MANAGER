# Security Policy

## Reporting a vulnerability

If you discover a vulnerability in AI Agent Manager, report it privately and do not open a public issue.

Include:
- A short description of the issue.
- Affected file or component.
- Steps to reproduce.
- Potential impact.
- Any proof of concept, if safe to share.

## Response expectations

Security-sensitive changes must be reviewed before merging.
Critical files are protected by CODEOWNERS.

## Safe disclosure

Do not disclose vulnerabilities publicly until a fix or coordinated release is available.
