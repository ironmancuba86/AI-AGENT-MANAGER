# Positioning

AI Agent Manager is the multi-tenant governance runtime for B2B SaaS teams that ship customer-facing AI agents.

## One-line category
Governed AI agent runtime for B2B SaaS.

## Core promise
Deploy agents safely across tenants with identity, policy, approvals, and auditability.

## What we are not
- Not a generic chatbot builder.
- Not a toy demo layer.
- Not a seat-based productivity wrapper.
