# Architecture

## Core layers

1. Identity layer.
2. Tenant routing layer.
3. Policy and approval layer.
4. Tool execution layer.
5. Logging and audit layer.
6. Observability and cost layer.

## Multi-tenant controls

- Identity-first execution.
- Explicit tenant scopes.
- Least privilege.
- Audit trails.
- Human approval gates.
- Redacted logs.

## Product posture

AI Agent Manager is the control layer for governed AI agents, not a generic chatbot builder.
