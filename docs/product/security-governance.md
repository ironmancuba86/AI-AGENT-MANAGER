# Security and Governance

## Principles
- Identity-first execution.
- Explicit tenant scopes.
- Least privilege.
- Audit-ready decision trails.
- Human approval for sensitive actions.
- Redacted logging.

## Controls
- Tenant isolation at the runtime and data layer.
- Scoped tool routing.
- Approval gates for risky actions.
- Rate limits per tenant.
- Traceability for every meaningful action.
