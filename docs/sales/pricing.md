# Pricing

## Pricing philosophy
Use hybrid pricing: platform fee + usage allowance + overage, with optional enterprise add-ons.

## Starter
- Fixed monthly platform fee.
- One tenant pilot.
- Limited agent count.

## Growth
- Higher platform fee.
- More tenants.
- Usage bucket with overage.

## Enterprise
- Custom contract.
- Advanced governance.
- Dedicated deployment or hardened isolation.
